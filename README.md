# zagyarakushi.gitlab.io

The source for my personal website, blog, and portfolio.

The site focuses on Linux, DevOps, infrastructure, open source, and software engineering, while documenting my projects and learning journey.

## ✨ Features

- Personal website
- Technical blog
- Project portfolio
- Markdown-based content
- Fast static site
- RSS feed

## 🚀 Development

Clone the repository:

```bash
git clone https://gitlab.com/zagyarakushi/zagyarakushi.gitlab.io.git
```

Build and serve the site using your preferred static site workflow.
